📖 About
This repository contains coursework and projects for GAT150 (Game Art & Technology), a comprehensive game development course focusing on 2D game programming fundamentals. The course covers essential game development concepts including graphics programming, game physics, collision detection, audio systems, and game architecture patterns.
🎯 Course Objectives

Game Programming Fundamentals: Learn core concepts of game development and programming
2D Graphics Programming: Implement 2D rendering systems using SDL2 and OpenGL
Game Physics: Develop physics systems for realistic game mechanics
Audio Integration: Implement sound effects and music systems
Game Architecture: Apply design patterns like Entity Component System (ECS)
Project Management: Complete multiple game projects from concept to completion

Clone the repository:

Install SDL2 dependencies:

Download SDL2 development libraries from libsdl.org
Extract to a Third Party or libs folder in your project
Configure include and library paths in Visual Studio


Open the solution file (.sln) in Visual Studio
Build and run the desired project

Linux/macOS

Install dependencies:
bash# Ubuntu/Debian
sudo apt-get install libsdl2-dev libsdl2-mixer-dev libsdl2-image-dev

# macOS (using Homebrew)
brew install sdl2 sdl2_mixer sdl2_image

Clone and build:
bashgit clone https://github.com/The-Legendary-Seabear/GAT150.git
cd GAT150
mkdir build && cd build
cmake ..
make
